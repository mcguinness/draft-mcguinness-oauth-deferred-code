# OAuth 2.0 Deferred Code Processing

This repository contains the Internet-Draft source for "OAuth 2.0 Deferred Code Processing".

The draft defines a token endpoint continuation mechanism for OAuth token requests that cannot complete synchronously. It introduces a `deferred_code` continuation reference, a deferred code grant type, optional interaction continuation metadata, authorization server metadata, and related security considerations.

The draft source is:

* `draft-mcguinness-oauth-deferred-code-processing.md`
